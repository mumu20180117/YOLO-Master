## 📖 项目介绍
YOLO Master是一款**纯单机全流程YOLO训练平台**，专为计算机视觉从业者和行业用户设计。无需任何编程基础，无需复杂环境配置，双击即可运行。

它整合了**项目管理→数据标注→图元提取→素材合成→模型训练→批量检测→报表导出**七大核心功能，形成完整闭环。通过独创的**一键图元提取+自动素材合成技术**，只需标注50张图片就能生成10000+高质量训练样本，模型精度可达95%以上。

所有数据100%本地运行，不会上传到任何服务器，完全符合电力、军工、医疗等所有涉密行业的要求。

## 🚀 核心功能
### 📁 项目管理
- 新建/加载/切换独立项目
- 随时新增分类，不影响历史数据
- 自动生成标准目录结构
- 所有数据独立隔离管理

### ✏️ 数据标注
- 内置手动标注工具，连续画框模式
- 自动保存标准YOLO格式标注
- 标注合法性自动校验
- 批量导入图片，支持JPG/PNG格式

### 🎨 一键图元提取
- 从标注图片中自动提取透明底图元
- 完美保留原图线条和颜色
- 按类别自动分类存储
- 支持批量提取和预览

### 🧩 自动素材合成
- 支持旋转、重叠、干扰物等参数配置
- 一键生成10万+高质量训练样本
- 自动划分训练集/验证集（9:1）
- 自动生成YOLO训练用dataset.yaml

### 🤖 一键模型训练
- 支持YOLOv5/v8/v11全系列模型
- 从头训练/迭代训练双模式
- 全参数可视化配置，内置最优参数
- 实时显示训练日志和进度
- 训练完成后自动保存最佳模型

### 📊 批量检测统计
- 加载项目内所有历史模型
- 支持加载外部模型（.pt/.onnx）
- 单张/批量检测图片
- 自动统计各类别数量
- 可视化展示检测结果

### 📑 人工复核与报表导出
- 支持手动新增/删除/修改检测框
- 一键导出标准化Excel报表
- 导出YOLO格式标注文件
- 报表格式可直接用于业务系统

## ⚡ 5分钟快速上手
### 1. 系统要求
- 操作系统：Windows 10/11 64位
- 处理器：Intel i5及以上
- 内存：8GB及以上
- 显卡：NVIDIA显卡（推荐RTX 3060及以上，支持CUDA加速）
- 硬盘：至少10GB可用空间

### 2. 完整工作流程
新建项目 → 导入 50 张真实图片 → 手动标注 → 一键提取图元 → 自动合成 10000 张样本 → 一键训练模型 → 批量检测 → 导出 Excel 报表


**整个流程不到5小时，模型精度可达95%以上**，而传统方法至少需要2周时间。
